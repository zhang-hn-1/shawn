  ```python

  ```

  目前为保证原始基线一致性，暂不修改。

  ```python
  Rotation.from_quat(self.base_quat.cpu().numpy())
  ```

  可能造成GPU与CPU频繁同步，影响并行训练速度，但当前不进行性能优化。

* 当前尚未建立普通 PPO、LH、SRU 的统一评估脚本，因此不能直接对比成功率、SPL、平均到达时间和动作平滑度。
* 当前无阻塞性环境问题，主要工作转为基线复现、历史模型整理和三组对照验证。
