# 白睛（专利）日报

## 今日完成
- 完成工业白睛眼象辅助分析专利材料整理，并提交专利预审申请。
- 对当前说明书、权利要求书、摘要及附图进行一致性检查。
- 重点检查网络结构附图与说明书技术方案对应关系，发现并整理多处需要优化的问题：
  - 输出模块中 GAP、FC、Softmax、类别概率以及 argmax 的数据流逻辑需要进一步规范；
  - 输出类别表述由“有斑块征象/无斑块征象”调整为更加符合辅助分析定位的“斑块阳性辅助分析提示/斑块阴性辅助分析提示”；
  - 注意力增强模块中通道注意力权重 Mc 与增强后特征 Xc 标注存在混淆，需要修正；
  - 门控融合模块需要明确表达：
    \[
    F_{fused}=G\odot F_{eg}+(1-G)\odot F_{el}
    \]
    避免被理解为门控权重直接相加；
  - 特征对齐模块需要区分通道投影与空间尺寸对齐过程。
- 基于专利审查角度，对附图表达风险进行梳理，降低模型输出被误解为医学诊断结果的风险。
- 完成双分支注意力融合网络架构图的修改方案设计。

## 今日决策
- 保持当前专利技术方案，不新增模型结构和实验内容。
- 后续修改重点放在：
  1. 附图规范化；
  2. 符号与公式一致性；
  3. 输出结果医学边界描述；
  4. 说明书与附图逐项对应检查。
- 不使用“诊断”“识别斑块病灶”等容易扩大技术效果的表述，统一采用“辅助分析提示”。
- 若预审反馈修改意见，优先围绕形式问题和一致性问题修订，不改变核心创新点。
